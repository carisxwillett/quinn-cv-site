# Quinn Willett: the drive

Quinn's CV as a scroll-to-drive trip through Los Angeles, seen from the driver's seat of his 2019 MG ZS EV. His friend Dani rides shotgun and narrates, a winking Mustang driver makes him jealous, and the drive ends at the Byte Burger drive-thru with his contact details on the menu.

Everything is in `index.html` (three.js from cdnjs, no build step). Quinn's details live in the `CV` object near the top of the script; edit that to update the site. "Read the full CV" gives a plain, printable version for anyone in a hurry.

To run it locally, open `index.html` in a browser, or serve the folder with any static server.
